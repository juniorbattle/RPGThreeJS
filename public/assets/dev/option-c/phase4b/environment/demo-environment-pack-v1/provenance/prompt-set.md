# Option C full-demo environment prompt set

## Shared production contract

All new sources were generated with the built-in image-generation tool as clean,
full-bleed 16:9 production backgrounds for a premium tactical JRPG / HD-2D
game. Every prompt required crisp modern fantasy pixel art, deliberate pixel
clusters, readable materials, controlled lighting, authored geography, strong
foreground/midground/background separation, and clear runtime staging space.

Every prompt also required an environment-only result with no people, creatures,
silhouettes, UI, text, labels, markers, selection circles, baked VFX, or
watermarks. The shared reject list was photorealism, painterly blur, generic AI
fantasy, muddy texture, excessive bloom, incoherent scale, and retro low-detail
pixel art.

## Asset-specific prompts

   red/blue Lion banners, palisade, supplies, campfire, outward mountain road.
2. `alaric-audience-master`: monumental Lion audience hall; authority/dais on
   the right, company lane on the left, dark stone, red/blue/gold heraldry.

   fires, supply shelter, forest perimeter, guarded road exit.
4. `first-refuge-morning-travel`: same refuge at morning departure; open gate,
   banked fires, road depth, restrained hope.
5. `forest-crossroads-tableau`: Forest Road v2 geography expanded to a readable
   Y-crossroads; ruins/waystone left, water right, citadel direction ahead.
6. `refugee-road-tableau`: worn stopping shoulder on the same route; ruts,
   abandoned bundles, cold fire ring, no people.
7. `roadside-event-tableau`: intimate route bend with two theatrical lanes,
   broken milestone left, stream right, long continuation lane.
8. `abandoned-cart-area-tableau`: damaged empty merchant cart and closed crates
   off the road; central lane remains clear and outcome-neutral.
9. `forest-ambush-area-tableau`: broad moonlit clearing with dark flanking
   undergrowth; Forest Road v2 landmark geography remains recognizable.
10. `valmir-road-master`: open mountain road to Bois-Clair/Valmir; old markers,
    ruined road architecture, ridge, distant neutral smoke.
