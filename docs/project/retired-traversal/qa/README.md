# Frozen physical QA provenance

These six original scripts are plain-text historical records. They imported or drove the removed physical Traversal runtime and are no longer executable QA entry points. Their original content is preserved for historical report interpretation; paths inside these texts describe their original source context.

Current production verification uses `tools/demo-continuous-production-qa.mjs`, the retained UI gallery runner, and the POI/lifecycle/save/combat tests. The original UI-kit script is archived here while its active gallery-only successor stays under `tools/`.

Historical reports, captures, seven directly linked art images and their metadata retain their original paths. No historical PASS is promoted to current map or retirement acceptance by this archive.
