# World, art and characters

Status: **LOCKED**.

The target is modern pixel art / HD-2D fantasy JRPG/tactical RPG. Maintain authored silhouettes, materials, palettes, lighting, and readable game scale across surfaces. Photorealism, generic anime, watercolor, and smooth generic 3D are not production substitutes.

Character System V2 masters and promoted combat/narrative poses are the current final visual ceiling. Use approved canonical media byte-identically where a task calls for promotion. A new character must match that visual family and have a declared pose/staging role. Do not silently remaster the whole cast or replace protected art during cleanup.

An environment family must remain recognizable across Journey/Travel, tableau, Traversal checkpoint, tactical combat, Combat Stage, and any associated cinematic: landmarks, palette, light direction, time, horizon, and scale must agree. A plateau or background painted for one surface is not automatically a valid world layer for another. Dedicated `PRODUCTION-CONTRACTS-POI-NAVIGATION-1` / [OD-2026-10-13-D](../autonomy/POI_NAVIGATION_OPERATOR_DECISION_2026-10-13.md), set 1.2.0: use an authored, readable geographical POI map with Option C / HD-2D / Pixel Diorama Fantasy palette, silhouettes, relief, paths and existing place names. Reuse approved resources only where appropriate; the former T0/T1/T3 forest-route target is superseded on navigation.

Before deleting or replacing media, inventory runtime, registry, manifest, CSS, tooling, QA, and historical evidence references. An asset deficit is a documented blocker for that deliverable, not permission to insert fake production art or silently substitute another visual style.
