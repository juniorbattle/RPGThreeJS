Sons FX — premier lot validé

Les huit sons et leur timbre sont validés par l’opérateur. Leur intégration dans le jeu est la prochaine étape. Les lecteurs ci-dessous permettent de les réécouter.

Lecture uniquement sur demande.

  1. Sélection · 75 msChangement explicite de POI ou onglet ; aucun survol ni focus automatique.
  2. Confirmer · 190 msAction acceptée et ouverture volontaire ; pas une promesse de sauvegarde.
  3. Retour · 150 msFermeture volontaire, Échap ou retour ; pas une annulation de faits déjà validés.
  4. Action refusée · 220 msRefus explicite avec message visible ; jamais une simple arrivée du focus sur un bouton désactivé.
  5. Sauvegarde réussie · 340 msConfirmation manuelle après écriture réellement réussie ; autosauvegardes silencieuses.
  6. Butin reçu · 460 msAffichage initial du résultat déjà accordé ; pas au rendu, à la fermeture ou au rechargement.
  7. Soins effectués · 430 msPotion ou repos réellement réussi ; ne déclenche aucun soin.
  8. Départ sur la carte · 230 msDéplacement accepté, une seule fois au départ ; pas de boucle ni son simulant une route physique.
