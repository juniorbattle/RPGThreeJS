## Locked visual doctrine

The demo targets a premium fantasy JRPG / tactical-RPG presented as a
high-density pixel-art diorama:

- strongly authored pixel environments;
- canonical readable character silhouettes;
- controlled palettes and modern atmospheric lighting;
- STATIC_TABLEAU-first interactive dialogue;
- tactical combat presentation;
- rare high-value cinematic video for major story events.

The game truth remains separate from visual presentation. Visual production
must replace or refine art behind existing presentation boundaries rather than
introducing a parallel gameplay or narrative runtime.

## Cinematic boundary

The project is now ready for the cinematic staging phase. Existing doctrine
continues to apply:

- VIDEO: major events, physical action, spectacle, entrances, outcomes and
  climaxes;
- STATIC_TABLEAU: sustained dialogue and choices;
- CINEMATIC_HOLD: dialogue-free punctuation;
- TRAVEL_STILL: connective journey presentation.

Character, environment, narrative and campaign truth must remain unchanged by
cinematic production unless a dedicated future audit explicitly authorizes a
change.
